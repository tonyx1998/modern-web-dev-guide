# Part II — Modern Stack

*Once you can ship, the next question is: which of the noise actually matters?*

This part has two layers. The **Trends** are directional — broad shifts in how 2026 apps are built. The **Tiers** are tactical — concrete tools, ranked by whether you should adopt them now, learn them later, or skip them entirely.

:::info[Read this part as a working dev]
Part II assumes you've shipped at least one full-stack project (Stage 11 in [Part I](/docs/roadmap/part-1-from-zero), or its equivalent from elsewhere). If you haven't, the trade-offs here won't land — adoption questions only matter when you have something to adopt them *into*.
:::

## What's in this part

- [Trends](/docs/roadmap/part-2-modern-stack/trends) — six 2026 directional shifts: server-first React, AI as a feature layer, type-safe everywhere, edge runtimes, local-first / sync engines, shadcn/ui.
- [Tier 1 — adopt now](/docs/roadmap/part-2-modern-stack/tier-1) — Drizzle + Zod, shadcn/ui, RSC + Server Actions, AI tool calling + RAG, Vitest + Playwright, Sentry + PostHog.
- [Tier 2 — worth knowing](/docs/roadmap/part-2-modern-stack/tier-2) — Cloudflare Workers + Hono, Convex/Zero, Stripe + Resend, Better Auth/Clerk, Turborepo, tRPC, Bun, Vercel AI SDK, Astro Server Islands, OpenTelemetry.
- [Tier 3 — skip or defer](/docs/roadmap/part-2-modern-stack/tier-3) — what the discourse loves but you don't need yet.

## How this pairs with Chapter 4 (Tech Stack)

[Chapter 4](/docs/stack) decodes *what each tool does and why it exists* — the reference. This part *tells you which ones to actually use right now* — the opinion.

If you want the wide view of every option, go to Chapter 4. If you want the short list, stay here.
